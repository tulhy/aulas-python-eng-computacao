# Aulas de Python — Engenharia de Computação

Exercícios de algoritmos em Python feitos durante o curso de Engenharia de Computação.

## Exercícios

| Arquivo | Conteúdo |
|---|---|
| [`01_primeiro_programa.py`](01_primeiro_programa.py) | Primeiros passos: `print`, variáveis, operações e leitura de números com `input` (soma com duas casas decimais) |
| [`02_condicionais_if.py`](02_condicionais_if.py) | Estruturas condicionais `if` / `elif` / `else`: aprovação por média, multa por velocidade, maior e menor de três números, aumento de salário |
| [`03_checkpoint_media_final.py`](03_checkpoint_media_final.py) | Checkpoint 1: média semestral descartando o menor checkpoint (40% checkpoints e sprints + 60% Global Solution) |

## Como executar

Precisa de Python 3 instalado. No terminal, dentro da pasta:

```bash
python 01_primeiro_programa.py
```

Os programas pedem os valores pelo teclado.
